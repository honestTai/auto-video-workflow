# 账号播放数据拉取与留存短板复盘

每次出片前先看自己账号最近几条作品的真实播放反馈，比盲目换题材更有效：重点盯住**观众在哪一秒划走**（2 秒跳出率、5 秒跳出率、平均播放时长）以及**看完后为什么没互动**（评论率、收藏率、吸粉率）。

## 一、怎么拉数据

通过 `douyin-video-mcp` 的两个工具（或命令行 `douyin_cli.py`，无需保持浏览器常驻，直接复用已保存的本机凭证）：

### 1. 拉取近期作品列表与账号均值基准线

- **MCP 工具**：`get_account_analytics(limit=10, sort_by="latest", min_views=20)`
- **命令行**：
  ```bash
  mcp/.venv/bin/python mcp/douyin_cli.py analytics --limit 10 --sort latest --min-views 20
  ```
- **返回内容**：
  - `works`：最近 `N` 条作品各自的播放量、封面展现、`bounce_rate_2s`（2秒跳出率）、**`bounce_rate_5s`（5秒跳出率 = `1 - completion_rate_5s`）**、`completion_rate_5s`（5秒完播率）、`completion_rate`（整体完播率）、`avg_view_second`（平均播放时长）、`avg_view_proportion`（平均播放进度）及点赞/评论/收藏/分享/吸粉率。
  - `overview`：自动剔除刚发布尚未跑量（`< min_views`）的新片后计算的近期均值（`averages`）、5 秒留存最佳作品（`best_5s_retention_work`）、5 秒跳出最高作品（`worst_5s_bounce_work`）以及自动短板提示（`diagnostics`）。

### 2. 单条代表作深度诊断（同级对比 + 流量来源）

挑近期 1–3 条有代表性的作品（比如播放最高的一条 + 跳出最高的一条），进一步看创作者中心官方同级对比：

- **MCP 工具**：`get_video_diagnosis(item_id="<作品ID或链接>")`
- **命令行**：
  ```bash
  mcp/.venv/bin/python mcp/douyin_cli.py diagnose 7700793742185303332
  ```
- **返回内容**：
  - `benchmarks`：播放量、2秒跳出率、**5秒跳出率**、5秒完播率、完播率、平均播放时长、点赞/评论/收藏/分享/吸粉率相对本账号历史同类作品基准值（`compare_value`）的增减比例与优劣判定（`better` / `worse`）。
  - `play_sources`：推荐页（`homepage_hot`）、搜索（`search`）、个人主页（`homepage`）、关注流（`follow`）等流量渠道占比及环比变化。

## 二、核心指标怎么看、怎么改（数据 → 创作处方）

不要只把数字抄一遍，每发现一项短板，都必须转化成**当期视频具体的文案、分镜或画面改动**：

| 数据信号 | 说明哪里出了问题 | 下一条视频的具体改进动作 |
|---|---|---|
| **2 秒跳出率偏高**（`bounce_rate_2s ≥ 35%`） | 首帧视觉太素、标题字太小，或第一句在寒暄/铺垫背景 | **改 S01 首帧与前 6 个字**：0.0s 画面直接出高对比大字结论或具象反差图；第一句直接抛反直觉结果或生活痛点，删掉一切背景寒暄 |
| **5 秒跳出率偏高**（`bounce_rate_5s ≥ 62%`，即 5 秒完播 `< 38%`） | 前 5 秒还在绕弯子讲概念/讲故事，观众不知道「跟我有什么关系」 | **改前两个分镜（0–5s）**：第 1 句戳观众正在踩的坑或直接亮硬数字，第 2 句明确承诺「看完这 60 秒你能拿走什么」，单分镜控制在 3–4.5 秒内快速切镜 |
| **平均播放时长短 / 播放进度低**（`avg_view_proportion < 12%`） | 中段说教感重、单镜头停留超过 8 秒画面不动、专有名词扎堆 | **改中段节奏与可视化**：总时长收紧到 60–85 秒；每个分镜 4–7 秒；每 15–20 秒必须出现一次具体数字、左右好坏对比卡或步骤进度条（`chapters` / `steps`） |
| **封面展现高但播放转化弱 / 搜索占比低** | 标题或封面三要素抽象、缺少具体检索词 | **改标题与封面三要素**：标题前 10 字放强悬念 + 核心检索词（如具体工具名/场景名）；封面大字直击痛点结果 |
| **点赞/收藏率偏低**（`favorite_rate < 0.3%`） | 看完觉得「知道了」但没有值得存下来照抄的东西 | **加利他清单分镜**：在片尾倒数第 2 幕放一张结构化「三条铁律 / 速查对照表 / 可直接照抄的指令卡」 |
| **评论率偏低**（`comment_rate < 0.1%`） | 结尾平铺直叙收尾，观众没有表达欲 | **埋真实讨论钩子**：在收尾或核心转折处留一个有立场的判断、实测悬念或观众有亲身经历的具体问题，并在发布简介末尾呼应 |
| **主页访问高但吸粉率偏低**（`subscribe_rate < 0.08%`） | 单条有用，但看不出账号持续更新的系列价值 | **强化栏目感**：保持统一的视觉皮肤/角色搭档与系列化选题切角 |

## 三、落盘要求

在 `<工程>/script.md` 顶部写一小节 **「账号数据复盘与本期改进」**（3–5 行即可）：

1. 近期有效样本均值（播放量、2s 跳出率、**5s 跳出率**、均播时长、互动率）及表现最好/最差作品的差异原因；
2. 本期重点攻克的 1–2 个指标短板；
3. 落在本期 S01–S02 钩子、分镜时长、画面密度或结尾互动上的具体改法。
