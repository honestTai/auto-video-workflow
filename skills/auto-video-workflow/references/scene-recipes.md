# 分镜配方

写画面不是自由创作，是**给每个分镜挑一个配方，再把内容填进去**。
11 个配方的完整代码在 `references/recipes/index.html`，每段前面的注释写了用法。先把它跑起来看一遍：

```bash
node SKILL/scripts/init-project.mjs SKILL/references/recipes     # 把 lib/ 同步进去
# 浏览器打开 SKILL/references/recipes/index.html?play 预览
```

## 1. 先填分镜表，再写代码

配音跑完之后、写 `index.html` 之前，在 `<工程>/script.md` 里加一节「分镜表」，每个分镜一行：

| 分镜 | 时长 | 这句在讲什么 | 配方 | 主素材 | 念到哪句 → 触发什么 | 角色站哪（有角色时填） |
|---|---|---|---|---|---|---|
| S01 | 5.02 | 价格差二十倍 | R01 钩子 | 数字 20 | 1.6s「二十倍」→ count | host 站大数字左边 |
| S02 | 2.40 | 第一部分：价格 | R02 章节卡 | — | — | 离场 |
| S03 | 6.40 | 官方定价页砍半 | R03 截图讲解 | `assets/shots/pricing.png` | 2.2s「砍半」→ cam-look + box | host 从截图上沿探出来 |
| S04 | 6.80 | 同一道题 3 块对 60 块 | R04 左右对比 | 两个数字 | 0.8s「三块」→ wake A；2.6s「六十」→ wake B | 0.8s 在 A 卡上；2.6s 换到 B 卡上 |

填表时检查这四件事，不满足就改表，不要带着问题去写代码：

1. **相邻两个分镜不用同一个配方。**
2. **R03 / R07 / R08 / R10（带真素材的配方）加起来不少于分镜总数的 1/3。** 素材不够就回第 1 步用 `shot.mjs` 再抓。
3. **每个分镜只有一个重点**，「主素材」一栏只能写一样东西。写了两样就拆成两个分镜（并且回去拆口播稿）。
4. **「触发」一栏的时间**来自 `project.json` 里该分镜 `lines[i].start` 减去分镜的 `start`。
5. **有角色时，「角色站哪」一栏不能每行都一样。** 角色要跟着内容走：讲到哪个元素就站到哪个元素旁边，要让位给大图时离场（写法见 `motion-lib-guide.md` 2.5 节）。

## 2. 配方速查

| 配方 | 一句话 | 用在哪 | 一条片子用几次 |
|---|---|---|---|
| **R01 钩子** | 一个超大数字或结论 + 一行说明 | 第 1 个分镜；每章的核心结论 | 2–3 |
| **R02 章节卡** | 大数字 01 + 章节名 | 每个大章节开头，1.5–2.5 秒 | 3–5 |
| **R03 截图讲解** | 一张大图，镜头推到重点并圈出来 | 官网、公告、榜单、文档、实测截图 | **越多越好** |
| **R04 左右对比** | 两张卡，念到谁亮谁，赢的放大 | 两个方案、两个模型、前后对比 | 1–2 |
| **R05 柱状图** | 图表 + 旁边一个大数字 | 榜单分数、价格、速度、数量 | 1–2 |
| **R06 清单** | 三行要点，念到哪条亮哪条 | 三个原因、三条建议 | 1–2 |
| **R07 挑着讲** | 几张图扇形排开，讲到谁谁抬起 | 几款产品、几个案例挨个点评 | 0–1 |
| **R08 快速过** | 一串图切片式换图 | 「我试了十几个」「这一年发了这么多」 | 0–1 |
| **R09 流程** | 步骤铺成一条路，走到哪步哪步亮 | 步骤、流程、时间线 | 0–1 |
| **R10 压上来** | 旧画面往后退变虚，新的一句话压上来 | 反转、提问、插一句结论 | 1–2 |
| **R11 收尾** | 结论 + 镜头拉远回看全片 | 最后一个分镜 | 1 |

口播内容和配方怎么对应：

| 这句口播在…… | 用 |
|---|---|
| 抛一个数字、一个反常识的结论 | R01 |
| 说「官方 / 论文 / 榜单 / 某某说」 | R03（必须有那张截图） |
| 比较两样东西 | R04；数量多于两个用 R05 |
| 列举并列的几条 | R06；每条都有图用 R07 |
| 讲先后顺序 | R09 |
| 说「但是」「其实」「问题来了」 | R10 |
| 说「总结一下」「所以」 | R11（片尾）或 R01（片中） |

## 3. 复制配方之后要改的地方

每个配方复制过来以后，按顺序改这几处，别的不要动：

1. `data-scene` 和 `data-d`：改成这个分镜的编号和配音秒数。
2. 文字：标题、标签、数字。`.fx-head` 里的 `<i>` 写来源或语境（「官方定价页」「同一道题」），`<h2>` 写这个分镜的结论（不是口播原文）。
3. 图片：`src` 换成 `assets/shots/` 下的真截图。容器的 `width / height` 按图的比例改，不要把图拉变形。
4. `@秒数`：全部改成分镜表里「触发」一栏的时间。**分镜变短了要检查每个时间都小于 `data-d`。**
5. R03 的定位块（`id="s3-key"` 那个透明 div）：`left / top / width / height` 改成盖住截图里要讲的那个区域；同一页面里 id 不能重复，每个分镜换个名字。

## 4. 素材怎么来

```bash
node SKILL/scripts/shot.mjs <工程> https://example.com/pricing --name pricing
node SKILL/scripts/shot.mjs <工程> https://example.com/blog/post --name post --height 2000    # 往下多截一屏
```

- 图存到 `<工程>/assets/shots/`。**每张都要打开看一眼**：有没有登录墙、弹窗、空白。不能用就换网址。
- 第 1 步搜资料时，每条要引用的事实都顺手把出处页面截下来，写进 `script.md` 的出处列表。
- 截不到的（要登录、视频里的画面）：下载的对标视频可以用 `ffmpeg -ss 秒数 -i 视频 -frames:v 1 assets/shots/名字.png` 抽帧。
- 实在没有图的分镜用 R01 / R04 / R05 / R06 这些纯数字、纯文字的配方，不要硬凑装饰图。

## 5. 配方不够用时

先想能不能拆成两个现有配方。确实需要新版式时：

- 仍然遵守 `motion-lib-guide.md` 第 2 节的铁律（先摆后讲、32px、一屏一重点）。
- 用第 6 节的现成版式类拼，定位用 `abs` + 明确坐标，内容放在 y 300–880 之间。
- 只用手册里列出的动效名。
